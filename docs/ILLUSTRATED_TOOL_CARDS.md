## Editing card artwork without writing code
1. Open [Pages CMS](https://app.pagescms.org) with authorised GitHub access to `omairarshad/sunnah-tools`.
2. Select source branch `feature/initial-site-and-tools` (not `hostinger-live`).
3. Open `Homepage layout & cards → Tools grid → Tool cards`.
4. Edit the `Large tool illustration` media upload field. Enter a useful `Illustration alt description`, and save.
5. Images must be approved local media paths under `/media/` or `/tool-art/`; the helper rejects remote URLs, `javascript:` links and traversals. Prefer an image close to a **5:3** aspect ratio with legible contrast, no tiny text, and a reasonable file size.
6. Source-branch changes trigger tests and publishing to the `hostinger-live` generated branch.

## QA & performance
- Site audit verifies all 22 illustration SVG assets are present and linked in built HTML, with consistent intrinsic dimensions.
- Browser smoke decodes each image, asserts a unique source and a descriptive alt, tests image-first layout at 1440px and large visuals at 390px, plus prior searches, filters, favourites and calculators.
- SVG content is generated by the project and contains no scripts or remote references. Avoid adding untrusted SVG uploads.
- No claims of SEO ranking improvement follow automatically from illustrations; titles, body text, accessible names and task functionality remain important for Search.
